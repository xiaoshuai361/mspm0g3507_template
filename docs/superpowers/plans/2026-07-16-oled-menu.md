# OLED Two-Level Menu Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Port the reference ZIP menu behavior into the MSPM0 template as a non-blocking two-level 6×8 OLED menu controlled by the ADC five-way key.

**Architecture:** Add a `Module/Menu` state machine independent of hardware input, then render its state through the existing OLED module. `App` maps Key5D press events to menu inputs and supplies read-only PID/status data without automatically starting motors, encoders, or the IMU.

**Tech Stack:** C11, TI Arm Clang 4.0.4 LTS, MSPM0 SDK 2.07.00.05, CCS managed build, existing Key5D and OLED modules.

### Task 2: Pure menu state machine

**Files:**
- Create: `Module/Menu/menu.h`
- Create: `Module/Menu/menu.c`

- [ ] **Step 1: Define pages and inputs**

```c
typedef enum { MENU_PAGE_MAIN, MENU_PAGE_TASKS, MENU_PAGE_PARAMETERS, MENU_PAGE_STATUS } Menu_Page;
typedef enum { MENU_INPUT_NONE, MENU_INPUT_UP, MENU_INPUT_DOWN, MENU_INPUT_BACK, MENU_INPUT_ENTER } Menu_Input;
```

- [ ] **Step 2: Implement deterministic transitions**

Main selection wraps across three entries. Task selection wraps across four entries. Enter opens the selected main page; Enter on the task page sets `activeTask` to 1–4; Back returns from any second-level page and preserves the main selection.

- [ ] **Step 3: Compile tests with implementation and verify GREEN**

Run TI Arm Clang on both files and require zero compile diagnostics.

### Task 3: 6×8 OLED renderer

**Files:**
- Modify: `Module/Menu/menu.c`
- Modify: `Module/Menu/menu.h`

- [ ] **Step 1: Add read-only view data**

The view data carries PID validity/values, IMU validity/angles, speed validity/left-right speed, key ADC, and active task.

- [ ] **Step 2: Render each page in eight-pixel rows**

Use `OLED_ShowString(..., 8, ...)`, ASCII text, `>` for selection, `*` for active task, and a maximum of 21 characters per line. Clear RAM before drawing and call `OLED_Refresh()` once per frame.
